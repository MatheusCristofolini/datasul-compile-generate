# Contexto da Fase 3: Interface Gráfica Desktop Estilo VS Code (GUI)

## Decisões

_Estas são decisões BLOQUEADAS._ O Planejador DEVE respeitá-las.

- A interface gráfica DEVE ser construída em Windows Forms nativo (`.NET Framework 4.8`), com visual Dark Theme inspirado no VS Code (`#1E1E1E` editor, `#252526` sidebar, `#007ACC` barra de status e botões primários, fonte monoespaçada `Consolas` para código).
- O painel superior DEVE permitir:
  - Selecionar o diretório raiz de programas (com botão `Procurar...` abrindo `FolderBrowserDialog`).
  - Digitar o termo de busca (ex: `es-teste-123`) e pressionar `Enter` ou clicar em `Buscar` (ou `Cancelar` durante a varredura).
  - Configurar extensões (`.p, .w, .i, .cls`), e checkboxes: `Rastrear Includes (.i -> .p/.w/.cls)`, `Ignorar Comentários (/* */ e //)`, `Palavra Inteira` e `Case Sensitive`.
- O painel central DEVE ser dividido (`SplitContainer`) estilo VS Code:
  - **Esquerda (Resultados e Seleção para Compilação):**
    - Aba/Lista de **Programas Compiláveis (`.p`, `.w`, `.cls`)** com **Checkboxes** para marcar/desmarcar programas individualmente ou em massa (`Marcar Todos` / `Desmarcar Todos`), exibindo o caminho relativo, quantidade de ocorrências e se o impacto é **Direto** ou **Via Include (`.i`)**.
    - Aba/Árvore de **Todas as Ocorrências (Estilo VS Code Search):** agrupada por arquivo (incluindo os `.i` onde o termo foi achado) e expandindo cada linha encontrada ou cadeia de include.
  - **Direita (Visualizador de Código + Preview do Script `.p`):**
    - Aba **Visualizador de Código-Fonte:** exibe o conteúdo do arquivo selecionado com numeração de linhas, destacando visualmente a linha exata da ocorrência ou da chamada `{include.i}` e rolando automaticamente até ela.
    - Aba **Preview do Script `.p` Gerado:** atualiza em tempo real o código `.p` conforme o usuário alterna entre **Modo com Log de Erros (`NO-ERROR` + `.log` na pasta do script)** vs **Modo Puro (`COMPILE ... SAVE.`)**, ou **Caminho Relativo (PROPATH)** vs **Caminho Absoluto**, com botões para **Salvar Arquivo `.p`...** e **Copiar Script**.

## Ideias Adiadas

- Editor completo de código-fonte com edição/salvamento (o visualizador é somente leitura para inspeção rápida).

## Discrição da IA

- Paleta de cores exata do tema VS Code Dark+ e atalhos de teclado (`Enter` para buscar, `Ctrl+S` para exportar `.p`).
