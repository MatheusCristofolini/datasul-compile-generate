# Roadmap do Projeto: Datasul Search & Compile Script Generator

### Fase 1: Motor de Busca e Rastreamento de Includes (Core Engine)
**Requisitos:** [REQ-01, REQ-02, REQ-03]
**Objetivo:** Construir a estrutura do projeto C# e o motor assíncrono de varredura de arquivos Progress (`.p`, `.w`, `.i`), incluindo a localização de linhas/ocorrências e o algoritmo de resolução reversa de includes (`.i` -> `.p`/`.w` que a utilizam).

### Fase 2: Gerador de Scripts Progress ABL (`.p`) com Log de Erros
**Requisitos:** [REQ-07, REQ-08]
**Objetivo:** Implementar o módulo gerador de código Progress (`.p`) suportando caminhos relativos (PROPATH) ou absolutos, modo simples (`COMPILE <prog> SAVE.`) e modo resiliente (`NO-ERROR` + geração de arquivo `.log` detalhado com erros de compilação sem travar o editor).

### Fase 3: Interface Gráfica Desktop Estilo VS Code (GUI)
**Requisitos:** [REQ-04, REQ-05, REQ-06, REQ-09]
**Objetivo:** Desenvolver a interface gráfica completa em Windows Forms (tema escuro moderno inspirado no VS Code) integrando o painel de busca, árvore de resultados com checkboxes, visualizador de código com destaque da linha e modal/painel de exportação do script `.p`.

### Fase 4: Build do Executável Portátil (`.exe`) e Validação End-to-End
**Requisitos:** [REQ-10]
**Objetivo:** Automatizar o script de compilação para gerar o executável único portátil (`DatasulCompileGen.exe`), validar com uma massa de testes realista de programas/includes Datasul e garantir zero dependências externas.
