# Roadmap do Projeto: Datasul Search & Compile Script Generator

### Fase 1: Motor de Busca e Rastreamento de Includes (Core Engine)
**Requisitos:** [REQ-01, REQ-02, REQ-03]
**Objetivo:** Construir a estrutura do projeto C# e o motor assíncrono de varredura de arquivos Progress (`.p`, `.w`, `.i`), incluindo a localização de linhas/ocorrências e o algoritmo de resolução reversa de includes (`.i` -> `.p`/`.w` que a utilizam).

### Fase 2: Gerador de Scripts Progress ABL (`.p`) com Log de Erros
**Requisitos:** [REQ-07, REQ-08]
**Objetivo:** Implementar o módulo gerador de código Progress (`.p`) suportando caminhos relativos (PROPATH) ou absolutos, modo simples (`COMPILE <prog> SAVE.`) e modo resiliente (`NO-ERROR` + geração de arquivo `.log` detalhado com erros de compilação sem travar o editor).

### Fase 3: Interface Gráfica Desktop Estilo VS Code (GUI Inicial)
**Requisitos:** [REQ-04, REQ-05, REQ-06, REQ-09]
**Objetivo:** Desenvolver a primeira versão funcional da interface gráfica integrando o painel de busca, árvore de resultados com checkboxes, visualizador de código e exportação do script `.p`.

### Fase 4: Build do Executável Portátil (`.exe`) e Validação End-to-End
**Requisitos:** [REQ-10]
**Objetivo:** Automatizar o script de compilação para gerar o executável único portátil (`DatasulCompileGen.exe`) e validar ponta a ponta.

### Fase 5: Redesign Completo da Interface com UI/UX Pro Max (WPF Vetorial Moderno)
**Requisitos:** [REQ-04, REQ-05, REQ-06, REQ-09, REQ-10]
**Objetivo:** Substituir a interface Windows Forms legada por uma interface **WPF Vetorial (DirectX)** de altíssimo nível visual seguindo o sistema de design `ui-ux-pro-max` (`design-system/MASTER.md`): paleta Dark Slate (`#090D16` / `#111827`), cantos arredondados, ícones vetoriais SVG (Lucide), KPI cards, badges semânticas (`DIRETO`, `VIA INCLUDE .i`), seletores segmentados modernos (sem comboboxes/tabs brancos do Win32) e scrollbars escuras, mantendo 100% da portabilidade em um único `.exe`.
