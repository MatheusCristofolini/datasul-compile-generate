# Pesquisa Técnica da Fase 3: Interface Gráfica Desktop Estilo VS Code (GUI)

## 1. Arquitetura Windows Forms Responsiva (.NET Framework 4.8)
- **DPI Awareness:** Habilitar `SetProcessDPIAware()` via `user32.dll` no `Program.cs` para que fontes e controles fiquem nítidos em monitores Full HD / 4K modernos.
- **Execução Assíncrona Não-Bloqueante:**
  - Utilizar `Progress<SearchProgressInfo>` que faz o marshaling automático para a UI thread no Windows Forms, atualizando a barra de status e o contador de arquivos sem travar a janela.
  - Utilizar `CancellationTokenSource` vinculado ao botão `Cancelar` para interromper buscas em diretórios gigantes instantaneamente.

## 2. Visualizador de Código com Destaque de Linha (`RichTextBox`)
- Quando o usuário clica em um arquivo ou em uma ocorrência específica (ex: Linha 42):
  - Carregamos o arquivo usando `ProgressCodeAnalyzer.ReadFileWithAutoEncoding` e formatamos com numeração de linhas alinhada (`   42 | FOR EACH es-teste-123 NO-LOCK:`).
  - Destacamos a linha da ocorrência com fundo de realce estilo VS Code (`#264F78`) e destacamos todas as ocorrências do termo buscado em amarelo/laranja vibrante, rolando o `RichTextBox` diretamente para a linha clicada (`ScrollToCaret()`).

## 3. Sincronização em Tempo Real do Preview do Script `.p`
- Sempre que o usuário marcar/desmarcar um programa no `ListView` de compiláveis, ou alterar os seletores de modo (`Com Log de Erros (NO-ERROR)` vs `Apenas COMPILE ... SAVE.`) ou formato de caminho (`Caminho Relativo (PROPATH)` vs `Caminho Absoluto`), o `CompileScriptGenerator` regenera instantaneamente o preview na aba `Script .p de Compilação`, permitindo inspecionar, copiar para a área de transferência ou salvar em disco via `SaveFileDialog`.
