# Contexto da Fase 1: Motor de Busca e Rastreamento de Includes (Core Engine)

## Decisões

_Estas são decisões BLOQUEADAS._ O Planejador DEVE respeitá-las.

- O motor de busca DEVE pesquisar por padrão nas extensões `.p`, `.w`, `.i` e `.cls` (permitindo customização pelo usuário).
- Os arquivos considerados **compiláveis** (que geram linhas `COMPILE <programa> SAVE.`) DEVEM ser `.p`, `.w` e `.cls`.
- Os arquivos `.i` (includes) NÃO são compiláveis diretamente; quando o termo buscado for encontrado em um `.i`, o motor DEVE realizar o **rastreamento reverso recursivo multinível** (ex: `A.i` -> `B.i` -> `C.p`/`.w`/`.cls`), com proteção contra loop infinito (conjunto de arquivos já visitados / prevenção de referência circular).
- A busca DEVE funcionar por padrão em todo o conteúdo do arquivo (como no VS Code), mas o motor DEVE oferecer a opção (flag booleana `IgnoreComments`) para ignorar ocorrências que estejam apenas dentro de comentários Progress (`/* ... */` de linha única ou múltiplas linhas, e `//`).
- O motor DEVE suportar busca Case-Insensitive (padrão no Progress) e Case-Sensitive opcional, bem como correspondência parcial ou palavra inteira.
- A varredura DEVE ser assíncrona, reportando progresso e suportando cancelamento via `CancellationToken`.

## Ideias Adiadas

_Estas coisas explicitamente NÃO acontecerão nesta fase._ O Planejador NÃO DEVE incluir tarefas para elas.

- Construção da tela gráfica Windows Forms (ficará na Fase 3).
- Formatação e exportação do script `.p` com `COMPILE ... SAVE NO-ERROR` e log de erros (ficará na Fase 2).
- Busca por múltiplos termos simultâneos ou Regex avançado (v2).

## Discrição da IA

_Áreas onde o usuário não forneceu preferência e autorizou a IA a fazer escolhas técnicas._

- Algoritmo de detecção de encoding de arquivos Progress (auto-detecção UTF-8 com fallback para `Windows-1252` / `ISO-8859-1` para preservar acentuação em fontes Datasul legados).
- Regex/parser utilizado para identificar chamadas de include `{...}` no Progress ABL (suportando `{caminho/arquivo.i}`, `{arquivo.i}`, passagem de argumentos `{arquivo.i &param=valor}` ou `{arquivo.i "arg"}`).
- Estrutura de classes de modelo (`SearchOptions`, `SearchMatch`, `FileSearchResult`, `CompilableTarget`) e testes de console/unidade para validar a Fase 1.
